# 🗣 Голосовой бот-уведомитель для МФЦ (МАУ «МФЦ Мясниковского района»)

---

## 📌 О проекте

**Продакшен-решение**, разработанное и внедренное в работу государственного учреждения (МАУ «МФЦ Мясниковского района»).

Система представляет собой автоматизированный комплекс голосового оповещения. Бот принимает текстовые сообщения и указания от администраторов через мессенджеры (**Telegram**, **VK**), преобразует текст в речь с помощью синтеза речи (TTS) и передает аудиофайлы на локальную систему воспроизведения в зале ожидания МФЦ.

### 🎯 Решаемая бизнес-задача

* **Автоматизация рутины:** Освобождение сотрудников от необходимости вручную делать объявления через микрофон.
* **Централизованное управление:** Возможность оперативной трансляции сообщений в зал ожидания из единого удобного интерфейса (мессенджера).
* **Стандартизация:** Обеспечение четкого, стабильного и качественного звучания объявлений для посетителей центра госуслуг.

## 🏗 Архитектура и стек технологий

```
┌───────────────────────────┐      Webhooks       ┌────────────────────────────────┐
│   Telegram / VK Client    │ ──────────────────> │     Python Bot Service         │
└───────────────────────────┘                     │    (aiogram + Webhooks)      │
                                                  └───────────────┬────────────────┘
                                                                  │
                                                                  ▼
┌───────────────────────────┐      REST API       ┌────────────────────────────────┐
│   Audio Playback System   │ <────────────────── │     TTS Engine & Storage       │
│     (Зал ожидания МФЦ)    │    (GET/POST)       │   (Синтез аудиофайлов MP3)   │
└───────────────────────────┘                     └────────────────────────────────┘

```

### 🛠 Технологический стек:

* **Язык программирования:** Python 3.10+
* **Фреймворки:** `aiogram` (асинхронная работа с Telegram API)
* **Интеграции:** Telegram API, VK API (через Webhooks)
* **Синтез речи (TTS):** Интеграция с движками Text-to-Speech для генерации медиафайлов
* **Протоколы взаимодействия:** REST API (GET/POST запросы) для обмена данными с аудиосистемой
* **Стандарты кода:** PEP 8, Flake8, Black

---

## 🚀 Ключевой функционал

* 📩 **Прием сообщений из мессенджеров:** Обработка входящих команд и текстов через вебхуки из Telegram и VK.
* 🎙 **Синтез речи (Text-to-Speech):** Преобразование произвольного или шаблонизированного текста в голосовые объявления формата MP3.
* 🔊 **Управление воспроизведением:** REST API для передачи аудиопотоков и команд проигрывания на целевое устройство в зале ожидания.
* 🔒 **Разграничение доступов:** Авторизация администраторов для предотвращения несанкционированных трансляций.

## 🛠 Локальный запуск и развертывание

### 1. Клонирование репозитория

```bash
git clone https://github.com/Gevork23/max_bot.git
cd max_bot

```

### 2. Настройка окружения

Создайте файл `.env` на основе имеющегося шаблона `.env.example`:

```bash
cp .env.example .env

```

Заполните необходимые ключи API (Telegram Bot Token, VK API Token, настройки TTS и параметры подключения).

### 3. Установка зависимостей и запуск

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# venv\Scripts\activate   # Для Windows

pip install -r requirements.txt
python main.py

```
